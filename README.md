# REVIT
REVIT to kieszonkowa diagnostyka auta bez kabli i kostek OBD. Połóż telefon na tunelu środkowym i rusz w trasę. Aplikacja wykorzystuje precyzyjne sensory smartfona, aby w czasie rzeczywistym mierzyć przyspieszenie, skuteczność hamowania, przeciążenia (siłę G) oraz wykrywać ściąganie pojazdu na boki. Szybki test kondycji auta w Twojej kieszeni.
